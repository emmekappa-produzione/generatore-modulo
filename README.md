# 📊 Generatore Modulo Ordine Resinex

Questo applicativo permette di generare in modo rapido e guidato i moduli d'ordine per la produzione.

### 🚀 Come utilizzare l'app:
1. Inserisci i dati dell'intestazione (Cliente, Commessa, Data).
2. Seleziona l'articolo e compila i campi tecnici richiesti.
3. Clicca su **Aggiungi Articolo** per inserirlo nella lista.
4. Una volta terminato, clicca su **Genera Excel** e scarica il file finale.

---
**Nota per il team:** I file generati seguono il modello ufficiale `modello.xlsx`. 
Per modifiche al software o alla lista prodotti, contattare l'amministratore.
